## 🔌 ENDPOINTS API REST

  GET     /api/usuarios                              ← Obtener todos
  GET     /api/usuarios/{id}                         ← Obtener por ID
  GET     /api/usuarios/buscar/identificacion/{id}   ← Buscar
  POST    /api/usuarios                              ← Crear
  PUT     /api/usuarios/{id}                         ← Actualizar
  DELETE  /api/usuarios/{id}                         ← Eliminar

## 📞 SOPORTE Y TROUBLESHOOTING

PROBLEMAS COMUNES

Problem:  Puerto 8080 ya está en uso
Solution: Cambiar en application.properties → server.port=8081

Problem:  Base de datos no conecta
Solution: Verificar MariaDB corriendo, usuario/contraseña en ConexionJDBC.java

Problem:  Maven no encontrado
Solution: Instalar desde https://maven.apache.org/download.cgi

Problem:  La interfaz no carga
Solution: Abrir F12 en navegador, revisar Console y Network

RECURSOS
  • Spring Boot Docs:   https://spring.io/projects/spring-boot
  • MDN Web Docs:       https://developer.mozilla.org/es/
  • MariaDB Docs:       https://mariadb.com/docs/
